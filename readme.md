# pi-weather-station

⚠️ WORK IN PROGRESS — DO NOT USE ⚠️

This project is currently under heavy development and the hardware/software
architecture is still changing.

The repository exists publicly for development history and collaboration, but:

- APIs may change without notice
- Hardware designs are incomplete
- PCB revisions are experimental
- Update/install mechanisms are unfinished
- No stability or security guarantees are provided
- The software has not been validated for unattended deployment

Use at your own risk.

## Current Goals

- Raspberry Pi / CM4 weather station platform
- Remote update and deployment support
- Modular sensor board architecture
- MCP3008 → ADS1114 migration
- Differential I2C sensor modules via PCA9615
- Async Python service architecture

## Status

Early prototype / experimental.
